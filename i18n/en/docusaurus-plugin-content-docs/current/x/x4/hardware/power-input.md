# Power Input Header

The Radxa X4 has an onboard **2-Pin 2.54mm** pitch power input header (designator J10, silkscreen PWR-IN), which can be used to power the board from an external 12V DC supply.

## Pinout

| Pin | Signal | Description |
| :--: | :--: | :--: |
| 1 | GND | Ground (negative) |
| 2 | ADP12V_IN | 12V power input (positive) |

![Radxa X4 power header polarity](/img/x/x4/x4_power_input_header_01.webp)

## External Power Supply

Connect the positive and negative terminals of a 12V power supply to the positive and negative pins on the board to power the board.

:::warning
Do not connect the power with wrong or reversed polarity. Improper operation may cause hardware damage.
:::
