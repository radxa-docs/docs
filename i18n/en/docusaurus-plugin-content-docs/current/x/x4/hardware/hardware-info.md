## Power Input Header Pinout

The Radxa X4 has an onboard 2-Pin 2.54mm pitch power input header (designator J10, silkscreen PWR-IN), which can be used to power the board from an external 12V DC supply, for example together with the [25W PoE+ HAT for X4](../accessories/25w-poe-plus-hat-for-x).

| Pin | Signal | Description |
| :--: | :--: | :--: |
| 1 | GND | Ground |
| 2 | ADP12V_IN | 12V power input |
