# Software Support Matrix

This page summarizes operating system support across Radxa platforms, with a dedicated sub-matrix per platform, so you can quickly find which systems (Yocto, Radxa OS (Debian), OpenWrt, Armbian, Android, FnOS, etc.) and which versions are supported on a given platform or product.

## Covered platforms

- **Rockchip**: [Rockchip Software Support Matrix](./rockchip.md) — covering Yocto, Radxa OS (Debian), OpenWrt, Armbian, Android and FnOS

More platforms (e.g. Allwinner, Qualcomm) will be added over time.
