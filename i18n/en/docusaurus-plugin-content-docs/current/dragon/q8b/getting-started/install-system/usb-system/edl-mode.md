# Entering EDL Mode

The method to enter EDL mode on Dragon Q8B is different from Q6A. Please refer to the [Entering EDL Mode](../../../low-level-dev/edl-mode) guide.

① : Press and hold the `EDL` button on the board

② : Connect a 20V Type-C power adapter (PD compatible)

③ : Release the `EDL` button on the board

④ : Connect the Dragon Q8B USB-C port to a computer USB port using a USB Type-C cable
