# Radxa OM-G720-L

Radxa OM-G720-L is an OSM compute module for integration into complete systems.

[Radxa Fogwise G720](../../fogwise/g720/README.md) is an industrial computer based on OM-G720-L, designed for industrial connectivity, device integration and field deployment. The complete computer and compute module have separate product names.
