# AIRbox Edge AI Computers

The AIRbox Edge AI Computers series focuses on edge AI inference, model execution and compute deployment. AIRbox and Fogwise are parallel product series under the Radxa brand.

- [Radxa AIRbox Q900](../fogwise/airbox-q900/README.md): an edge AI computer.
- [Radxa AIRbox](../fogwise/airbox/README.md): a SOPHON SG2300x based edge AI computer.
- [Fogwise Industrial Computers](../fogwise/README.md): industrial connectivity and field deployment.
