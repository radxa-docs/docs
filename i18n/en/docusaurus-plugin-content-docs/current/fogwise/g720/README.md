# Radxa Fogwise G720

Radxa Fogwise G720 is an industrial computer for industrial connectivity, device integration and field deployment. It belongs to the [Fogwise Industrial Computers series](../README.md).

## Computer and compute module

Fogwise G720 is based on the [Radxa OM-G720-L](../../osm/om-g720-l/README.md) OSM compute module. Fogwise G720 is the complete industrial computer; OM-G720-L is the compute module used for system integration.
