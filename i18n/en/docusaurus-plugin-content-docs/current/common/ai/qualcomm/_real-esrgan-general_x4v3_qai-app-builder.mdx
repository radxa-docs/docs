This document describes using the [QAI AppBuilder](../qai-appbuilder) Python API to run inference with the [Real-ESRGAN-General-x4v3](https://aihub.qualcomm.com/models/real_esrgan_general_x4v3) super-resolution model on the Qualcomm® Hexagon™ Processor (NPU).

**Supported devices**

| Device               | SoC      |
| -------------------- | -------- |
| Dragon Q6A           | QCS6490  |
| Dragon Q8B           | SC8280XP |
| Fogwise® AIRbox Q900 | QCS9075  |

## Install QAI AppBuilder

:::tip

1. Install QAI AppBuilder by following the [**QAI AppBuilder installation guide**](../qai-appbuilder).

2. Configure ADSP environment variables as described in [**Create ADSP environment variables**](../qai-appbuilder#create-adsp-environment-variables).
   :::

## Run the sample

### Install dependencies

Install sample dependencies in the activated virtual environment:

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless
```

</NewCodeBlock>

### Run the script

- Enter the upstream samples directory

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

Run inference (Linux **requires** `--chipset`, or model download may fail)

<Tabs queryString="platform">
<TabItem value="QCS6490" default={props.tag === "qcs6490"} attributes={{className: props.tag !== "qcs6490" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Super_Resolution/real_esrgan_general_x4v3/real_esrgan_general_x4v3.py --chipset 6490
```

</NewCodeBlock>

</TabItem>

### Expected result

On Dragon Q6A, a successful run writes:

```text
ComputerVision/Super_Resolution/real_esrgan_general_x4v3/output.jpg
```

Without a display, `Error: no DISPLAY environment variable specified` may appear; ignore it if the output file exists and the exit code is 0.

:::tip
Launcher alternative:

```bash
python3 run_inference.py --model real_esrgan_general_x4v3 --args "--chipset 6490"
```

:::
