This document describes how to use the [QAI AppBuilder](../qai-appbuilder) Python API to run inference with the [MediaPipe-Hand-Detection](https://aihub.qualcomm.com/models/mediapipe_hand) hand pose recognition model on Qualcomm® Hexagon™ Processor (NPU).

**Supported devices**

| Device               | SoC     |
| -------------------- | ------- |
| Fogwise® AIRbox Q900 | QCS9075 |

## Install QAI AppBuilder

:::tip

1. Install QAI AppBuilder by following the [**QAI AppBuilder installation guide**](../qai-appbuilder).

2. Configure ADSP environment variables as described in [**Create ADSP environment variables**](../qai-appbuilder#create-adsp-environment-variables).
   :::

## Run the sample

### Install dependencies

Install sample dependencies in the activated virtual environment:

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless pygame
```

</NewCodeBlock>

The script also looks under `~/.qaihm` for [MediaPipePyTorch](https://github.com/zmurez/MediaPipePyTorch) (provides `blazepalm` and related modules). If missing:

<NewCodeBlock tip="Device" type="device">

```bash
mkdir -p ~/.qaihm
git clone --depth 1 https://github.com/zmurez/MediaPipePyTorch.git ~/.qaihm/MediaPipePyTorch
```

</NewCodeBlock>

### Run the script

- Enter the upstream samples directory

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

- Prepare input data (camera UI needs a GUI; use a static image in headless environments)

<div style={{ textAlign: "center" }}>
  <img
    src="/en/img/fogwise/airbox-q900/qairt_mediapipe_hand_input.webp"
    style={{ width: "65%" }}
  />
  input image
</div>

- Run inference

    <NewCodeBlock tip="Device" type="device">

  ```bash
  python3 ComputerVision/Pose_Estimation/mediapipe_hand/mediapipe_hand.py \
    --chipset 9075 \
    --imagefile /path/to/hand_image.png \
    --displayPredict False \
    --DemoMode False
  ```

    </NewCodeBlock>

- Example result: `output.jpg` is written in the sample directory

<div style={{ textAlign: "center" }}>
  <img
    src="/en/img/fogwise/airbox-q900/qairt_mediapipe_hand_output.webp"
    style={{ width: "65%" }}
  />
  output image
</div>

:::tip
The first run downloads `handdetector` and `landmarkdetector` via Qualcomm® AI Hub. Prefer `--imagefile` when no display is available, and use `opencv-python-headless` to avoid Qt plugin initialization failures.

```bash
python3 run_inference.py --list
python3 run_inference.py --model mediapipe_hand --args "--chipset 9075 --imagefile /path/to/hand_image.png --displayPredict False --DemoMode False"
```

:::
