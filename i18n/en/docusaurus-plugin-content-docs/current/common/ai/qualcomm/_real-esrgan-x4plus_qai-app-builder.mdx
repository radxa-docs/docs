This document describes using the [QAI AppBuilder](../qai-appbuilder) Python API to run inference with the [Real-ESRGAN-x4plus](https://aihub.qualcomm.com/models/real_esrgan_x4plus?domain=Computer+Vision&useCase=Super+Resolution&chipsets=qualcomm-qcs6490-proxy) super-resolution model on the Qualcomm® Hexagon™ Processor (NPU).

**Supported devices**

| Device               | SoC      |
| -------------------- | -------- |
| Dragon Q6A           | QCS6490  |
| Dragon Q8B           | SC8280XP |
| Fogwise® AIRbox Q900 | QCS9075  |

## Install QAI AppBuilder

:::tip

1. Install QAI AppBuilder by following the [**QAI AppBuilder installation guide**](../qai-appbuilder).

2. Configure ADSP environment variables as described in [**Create ADSP environment variables**](../qai-appbuilder#create-adsp-environment-variables).
   :::

## Run the sample

### Install dependencies

Install sample dependencies in the activated virtual environment:

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless
```

</NewCodeBlock>

### Run the script

- Enter the upstream samples directory

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

- Prepare input data (the sample provides a default image)

<div style={{ textAlign: "center" }}>
  <img
    src="/en/img/fogwise/airbox-q900/qairt_real_esrganx4plus_input.webp"
    style={{ width: "65%" }}
  />
  input image
</div>

Run inference

:::warning
On QCS6490 / SC8280XP, **do not use the default float DLC**. The default `.dlc` path fails with `The SocModel doesn't support FP16`. Use **`--bin`** to download the precompiled HTP context binary.
:::

<Tabs queryString="platform">
<TabItem value="QCS6490" default={props.tag === "qcs6490"} attributes={{className: props.tag !== "qcs6490" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Super_Resolution/real_esrgan_x4plus/real_esrgan_x4plus.py --chipset 6490 --bin --no_show
```

</NewCodeBlock>

</TabItem>
<TabItem value="SC8280XP" default={props.tag === "sc8280xp"} attributes={{className: props.tag !== "sc8280xp" && "tab_none"}}>

:::tip
SC8280XP and QCS6490 both use Hexagon V68. Use `--chipset 6490` with `--bin`.
:::

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Super_Resolution/real_esrgan_x4plus/real_esrgan_x4plus.py --chipset 6490 --bin --no_show
```

</NewCodeBlock>

</TabItem>
<TabItem value="QCS9075" default={props.tag === "qcs9075"} attributes={{className: props.tag !== "qcs9075" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Super_Resolution/real_esrgan_x4plus/real_esrgan_x4plus.py --chipset 9075 --no_show
```

</NewCodeBlock>

:::tip
On QCS9075 the Hub default is a `.bin` HTP context that runs as-is. Use `--no_show` on headless sessions.
:::

</TabItem>
</Tabs>

`--no_show` avoids opening an image viewer on headless SSH sessions.

### Expected result

A successful run writes:

```text
ComputerVision/Super_Resolution/real_esrgan_x4plus/output.png
```

:::tip
Launcher alternative:

```bash
python3 run_inference.py --model real_esrgan_x4plus --args "--chipset 6490 --bin --no_show"
```

:::
