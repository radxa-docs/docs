This document describes how to use the [QAI AppBuilder](../qai-appbuilder) Python API to run inference with the [Facial-Landmark-Detection](https://aihub.qualcomm.com/models/facemap_3dmm) facial landmark detection model on Qualcomm® Hexagon™ Processor (NPU).

**Supported devices**

| Device               | SoC     |
| -------------------- | ------- |
| Fogwise® AIRbox Q900 | QCS9075 |

## Install QAI AppBuilder

:::tip

1. Install QAI AppBuilder by following the [**QAI AppBuilder installation guide**](../qai-appbuilder).

2. Configure ADSP environment variables as described in [**Create ADSP environment variables**](../qai-appbuilder#create-adsp-environment-variables).
   :::

## Run the sample

### Install dependencies

Install sample dependencies in the activated virtual environment:

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless scikit-image onnxruntime
```

</NewCodeBlock>

### Run the script

- Enter the upstream samples directory

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

- Prepare input data (use the sample input if provided, or pass script arguments)

<div style={{ textAlign: "center" }}>
  <img
    src="/en/img/fogwise/airbox-q900/qairt_facemap_3dmm_input.webp"
    style={{ width: "65%" }}
  />
  input image
</div>

- Run inference

    <NewCodeBlock tip="Device" type="device">

  ```bash
  python3 ComputerVision/Face_Recognition/facemap_3dmm/facemap_3dmm.py --chipset 9075
  ```

    </NewCodeBlock>

On AIRbox Q900 the sample may prefer the ONNX float model (requires `onnxruntime`). A successful run writes `output.jpg` and may print `ONNX model inference time: ... ms`.

- Example result

:::tip
The first run downloads the model via Qualcomm® AI Hub (network-dependent). You can also use the launcher from `samples`:

```bash
python3 run_inference.py --list
python3 run_inference.py --model facemap_3dmm --args "--chipset 9075"
```

:::
