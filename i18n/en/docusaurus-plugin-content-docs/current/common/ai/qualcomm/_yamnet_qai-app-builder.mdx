This document explains how to use the [QAI AppBuilder](../qai-appbuilder) Python API to perform inference with the [YamNet](https://aihub.qualcomm.com/compute/models/yamnet) audio classification model using the Qualcomm® Hexagon™ Processor (NPU).

**Supported devices**

| Device               | SoC     |
| -------------------- | ------- |
| Fogwise® AIRbox Q900 | QCS9075 |

## Install QAI AppBuilder

:::tip

1. Install QAI AppBuilder by following the [**QAI AppBuilder installation guide**](../qai-appbuilder).

2. Configure ADSP environment variables as described in [**Create ADSP environment variables**](../qai-appbuilder#create-adsp-environment-variables).
   :::

## Run the sample

### Install dependencies

Install sample dependencies in the activated virtual environment:

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless soxr soundfile resampy
```

</NewCodeBlock>

### Run the script

- Enter the upstream samples directory

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

- Prepare input data (use the sample input if provided, or pass script arguments)

<div style={{ textAlign: "center" }}>

      <audio

src="https://qaihub-public-assets.s3.us-west-2.amazonaws.com/qai-hub-models/models/yamnet/v1/speech_whistling2.wav"
controls

>

              </audio>
              <p><em>input audio</em></p>

          </div>

- Run inference

    <NewCodeBlock tip="Device" type="device">

  ```bash
  python3 audio/Audio_Classification/yamnet/yamnet.py --chipset 9075
  ```

    </NewCodeBlock>

The default input is the bundled `input.wav`. On success the terminal prints top-5 labels, for example:

```text
Top 5 predictions:
Whistling | Alarm | Whistle | Field recording | Rattle (instrument)
```

:::tip
The first run downloads the model via Qualcomm® AI Hub and needs audio libraries such as `soxr`. You can also use the launcher from `samples`:

```bash
python3 run_inference.py --list
python3 run_inference.py --model yamnet --args "--chipset 9075"
```

:::
