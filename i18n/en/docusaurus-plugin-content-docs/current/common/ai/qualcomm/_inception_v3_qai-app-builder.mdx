This document describes using the [QAI AppBuilder](../qai-appbuilder) Python API to run inference with the [Inception-v3](https://aihub.qualcomm.com/models/inception_v3?domain=Computer+Vision&useCase=Image+Classification&chipsets=qualcomm-qcs6490-proxy) image classification model on the Qualcomm® Hexagon™ Processor (NPU).

**Supported devices**

| Device               | SoC      |
| -------------------- | -------- |
| Dragon Q6A           | QCS6490  |
| Dragon Q8B           | SC8280XP |
| Fogwise® AIRbox Q900 | QCS9075  |

## Install QAI AppBuilder

:::tip

1. Install QAI AppBuilder by following the [**QAI AppBuilder installation guide**](../qai-appbuilder).

2. Configure ADSP environment variables as described in [**Create ADSP environment variables**](../qai-appbuilder#create-adsp-environment-variables).
   :::

## Run the sample

### Install dependencies

Install sample dependencies in the activated virtual environment:

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless
```

</NewCodeBlock>

### Run the script

- Enter the upstream samples directory

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

Run inference (Linux requires `--chipset`; the sample ships with `input.jpg`)

<Tabs queryString="platform">

<TabItem value="QCS6490" default={props.tag === "qcs6490"} attributes={{className: props.tag !== "qcs6490" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Image_Classification/inception_v3/inception_v3.py --chipset 6490
```

</NewCodeBlock>

</TabItem>

<TabItem value="SC8280XP" default={props.tag === "sc8280xp"} attributes={{className: props.tag !== "sc8280xp" && "tab_none"}}>

:::tip
SC8280XP and QCS6490 both use Hexagon V68. Use `--chipset 6490` when downloading models.
:::

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Image_Classification/inception_v3/inception_v3.py --chipset 6490
```

</NewCodeBlock>

</TabItem>

<TabItem value="QCS9075" default={props.tag === "qcs9075"} attributes={{className: props.tag !== "qcs9075" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">

python3 ComputerVision/Image_Classification/inception_v3/inception_v3.py --chipset 9075

</NewCodeBlock>

</TabItem>

</Tabs>

Optional image path:

```bash
python3 ComputerVision/Image_Classification/inception_v3/inception_v3.py --chipset 6490 --image ComputerVision/Image_Classification/inception_v3/input.jpg
```

### Expected result

On Dragon Q6A (`--chipset 6490`), the default input produces output similar to:

```text
Top 5 predictions for image:

Samoyed 0.999714911
white wolf 0.0001396882
Arctic fox 0.0001165446
Pomeranian 0.000006424
Great Pyrenees 0.000006424
```

HTP / FastRPC WARNING lines may appear and can be ignored when inference succeeds.

:::tip
Launcher alternative:

```bash
python3 run_inference.py --model inception_v3 --args "--chipset 6490"
```

:::
