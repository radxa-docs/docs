# Install System to microSD Card

:::tip

When using microSD card / eMMC to boot on ROCK 5B / 5B+, you need to erase the SPI Flash first. Refer to the [Erase SPI Flash](../../../low-level-dev/install-os/rkdevtool_spi.md) tutorial.

:::

<BalenaEtcherUse download_page="../../../download" />

## Boot the System

After completing the system installation, insert the microSD card into the microSD card slot of the board, then power the board with a power adapter to boot the Android system.
