# Install System to eMMC Module

:::tip

When using microSD card / eMMC to boot on ROCK 5B, you need to erase the SPI Flash first. Refer to the [Erase SPI Flash](../../../low-level-dev/install-os/rkdevtool_spi.md) tutorial.

ROCK 5B+ has no eMMC module interface.

:::

<BalenaEtcherUse download_page="../../../download" />

## Boot the System

After completing the system installation, install the eMMC module into the eMMC interface of the board, then power the board with a power adapter to boot the Android system.
