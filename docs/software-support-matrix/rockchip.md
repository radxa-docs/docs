# 瑞芯微软件支持矩阵

本页汇总 Radxa 基于 Rockchip（RK）平台的在售 / 维护中产品的操作系统支持情况，覆盖 Yocto、Radxa OS（Debian）、OpenWrt、Armbian、Android 与 FnOS，按 SoC 分组、同一 SoC 下的产品逐行列出。

:::tip 如何阅读本表

- 单元格格式：`系统版本 | 内核版本`，例如 `Debian 12 Desktop | RK 6.1` 表示 Debian 12 桌面版并使用 RK 6.1 内核
- 同一单元格内多个条目以英文逗号分隔
- `N/A`：官方不提供该系统
- `Available`：官方提供可用镜像
- Armbian 列中的 `Standard` / `Community` / `Platinum` 为 Armbian 官方支持等级
- 空单元格：暂无公开支持信息
  :::

:::caution 版本说明
表中的系统与内核版本为当前公开镜像对应的版本，随镜像发布周期更新；具体镜像下载与安装方式请以对应产品页面和系统文档为准。
:::
