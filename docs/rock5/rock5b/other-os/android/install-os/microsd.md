# 安装系统到 microSD 卡

:::tip

ROCK 5B / 5B+ 使用 microSD 卡 / eMMC 启动时，需要先擦除 SPI Flash，参考 [擦除 SPI Flash](../../../low-level-dev/install-os/rkdevtool_spi.md) 教程。

:::

<BalenaEtcherUse download_page="../../../download" />

## 启动系统

完成系统的安装后，将 microSD 卡安装到主板的 microSD 卡槽中，然后使用电源适配器给主板供电，即可启动 Android 系统.
