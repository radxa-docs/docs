# 安装系统到 NVMe SSD

:::tip

使用最新版本进行系统安装，旧版本可能会出现 `Write LBA failed !` 错误。

ROCK 5B+ 有两个 NVMe SSD 接口，目前仅有一个 NVMe SSD 接口可用，另一个接口暂不支持启动安卓系统，若无法启动系统，请尝试将 NVMe SSD 安装到另一个接口。

:::

<RockchipNVMe />

## 启动系统

完成系统的安装后，使用电源适配器给主板供电，即可启动 Android 系统.
