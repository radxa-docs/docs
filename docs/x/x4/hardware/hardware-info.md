## 电源输入接口引脚定义

Radxa X4 板载一个 2-Pin 2.54mm 间距的电源输入排针（位号 J10，丝印 PWR-IN），可用于通过外部 12V 直流电源为整板供电，例如配合 [25W PoE+ HAT for X4](../accessories/25w-poe-plus-hat-for-x) 使用。

| 引脚 | 信号 | 说明 |
| :--: | :--: | :--: |
| 1 | GND | 电源地 |
| 2 | ADP12V_IN | 12V 电源输入 |
