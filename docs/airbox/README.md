# AIRbox AI 算力盒子

AIRbox AI 算力盒子系列面向边缘 AI 推理、模型运行与算力部署。AIRbox 与 Fogwise 是 Radxa 品牌下的平行产品系列。

- [Radxa AIRbox Q900](../fogwise/airbox-q900/README.md)：面向边缘 AI 计算的算力盒子。
- [Radxa AIRbox](../fogwise/airbox/README.md)：基于 SOPHON SG2300x 的边缘 AI 计算设备。
- [Fogwise 工业电脑](../fogwise/README.md)：面向工业接口连接与现场部署。
