# EDL 按键

瑞莎 Dragon Q8B 板载 EDL 按键，用于进入 EDL 模式，EDL 模式是高通处理器设备中的一种紧急下载模式，主要用于紧急修复、刷写固件或解锁设备。

## 使用指南

按照以下步骤操作，主板将进入 EDL 模式。

详细步骤：

1. 按住 EDL 按键
2. 使用 USB Type-C 数据线连接 Dragon Q8B 的 USB-C 接口和电脑的 USB 接口（正常情况下电源指示灯绿色常亮）
3. 松开 EDL 按键
4. 连接 20V Type-C 电源适配器（兼容 PD 协议）

正常情况下，主板会进入 EDL 模式。
