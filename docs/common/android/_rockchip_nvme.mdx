介绍如何将 Android 系统安装到 NVMe SSD 中。

## 硬件连接

将 NVMe SSD 安装到主板的 M.2 M Key 接口中，然后让主板<a href={props?.download_page ?? '../../../low-level-dev/install-os/rkdevtool_maskrom'}>进入 Maskrom 模式</a>.

## 下载系统

使用 PC 访问 <a href={props?.download_page ?? '../../../download'}>资源汇总下载</a> 页面，下载系统镜像并解压到本地上。

## 安装系统

<Tabs>
<TabItem value="os-1" label="Windows" default>

- 安装驱动

下载并解压 [DriverAssistant](https://dl.radxa.com/tools/windows/DriverAssitant.zip) 文件，找到 `DriverInstall.exe` 文件并以管理员身份运行，根据提示安装驱动。

- 使用 RKDevTool 工具

下载并解压 [RKDevTool](https://dl.radxa.com/tools/windows/RKDevTool_Release.zip) 工具，其中 `RKDevTool.exe` 就是可执行程序，直接双击可以打开使用软件。

<div style={{ textAlign: "center" }}>
  <img
    src="/img/common/radxa-os/install-system/rkdevtool_android.webp"

1. 点击 `Firmware` 按钮，选择解压后的系统镜像文件。

2. 点击 `Upgrade` 按钮，开始安装系统到 NVMe SSD。

</TabItem>
<TabItem value="os-2" label="Linux">

下载 [Update_Tool_V2.30](https://dl.radxa.com/tools/linux/upgrade_tool_v2.30_for_linux.zip) 工具并解压，然后在终端中进入解压后的目录，执行以下命令:

```bash
sudo chmod +x upgrade_tool
sudo ln -s "$(pwd)/upgrade_tool" /usr/local/bin/upgrade_tool
```

使用以下命令安装系统到 NVMe SSD：将 `<image>` 替换为解压后的系统镜像文件路径。

```bash
sudo upgrade_tool uf <image>
```

</TabItem>
