此文档讲述使用 [QAI AppBuilder](../qai-appbuilder) Python API 利用 Qualcomm® Hexagon™ Processor (NPU) 推理 [Real-ESRGAN-General-x4v3](https://aihub.qualcomm.com/models/real_esrgan_general_x4v3)
图像超分模型。

**示例支持设备**

| 设备                 | SoC      |
| -------------------- | -------- |
| Dragon Q6A           | QCS6490  |
| Dragon Q8B           | SC8280XP |
| Fogwise® AIRbox Q900 | QCS9075  |

## 安装 QAI AppBuilder

:::tip

1. 请根据 [**QAI AppBuilder 安装方法**](../qai-appbuilder) 安装 QAI AppBuilder。

2. 请根据 [**创建 ADSP 环境变量**](../qai-appbuilder#创建-adsp-环境变量) 配置 ADSP 环境变量。
   :::

## 运行示例

### 安装依赖

在已激活的虚拟环境中安装示例依赖：

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless
```

</NewCodeBlock>

### 运行脚本

- 进入上游示例目录

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

执行推理（Linux **必须**指定 `--chipset`，否则可能无法下载到对应模型）

<Tabs queryString="platform">

<TabItem value="QCS6490" default={props.tag === "qcs6490"} attributes={{className: props.tag !== "qcs6490" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Super_Resolution/real_esrgan_general_x4v3/real_esrgan_general_x4v3.py --chipset 6490
```

</NewCodeBlock>

</TabItem>

<TabItem value="SC8280XP" default={props.tag === "sc8280xp"} attributes={{className: props.tag !== "sc8280xp" && "tab_none"}}>

:::tip
SC8280XP 与 QCS6490 同为 Hexagon V68，下载模型时使用 `--chipset 6490`。
:::

<NewCodeBlock tip="Device" type="device">

```bash

```

</NewCodeBlock>

</TabItem>

<TabItem value="QCS9075" default={props.tag === "qcs9075"} attributes={{className: props.tag !== "qcs9075" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">


</NewCodeBlock>

</TabItem>

</Tabs>

### 预期结果

在 Dragon Q6A 上推理成功后，会在示例目录生成：

```text
ComputerVision/Super_Resolution/real_esrgan_general_x4v3/output.jpg
```

无图形界面时可能出现 `Error: no DISPLAY environment variable specified`，只要输出文件已生成且退出码为 0，可忽略。

:::tip
也可使用启动器：

```bash
python3 run_inference.py --model real_esrgan_general_x4v3 --args "--chipset 6490"
```

:::
