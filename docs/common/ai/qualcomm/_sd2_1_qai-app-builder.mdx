此文档讲述使用 [QAI AppBuilder](../qai-appbuilder) Python API 利用 Qualcomm® Hexagon™ Processor (NPU) 推理 [Stable-Diffusion-v2.1](https://aihub.qualcomm.com/iot/models/stable_diffusion_v2_1)
文生图模型。

**示例支持设备**

| 设备                 | SoC     |
| -------------------- | ------- |
| Fogwise® AIRbox Q900 | QCS9075 |

## 安装 QAI AppBuilder

:::tip

1. 请根据 [**QAI AppBuilder 安装方法**](../qai-appbuilder) 安装 QAI AppBuilder。

2. 请根据 [**创建 ADSP 环境变量**](../qai-appbuilder#创建-adsp-环境变量) 配置 ADSP 环境变量。
   :::

## 运行示例

### 安装依赖

在已激活的虚拟环境中安装示例依赖：

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless transformers diffusers
```

</NewCodeBlock>

### 运行脚本

- 进入上游示例目录

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

- 准备输入数据（示例自带输入文件时可直接运行；也可按脚本参数指定）

<div style={{ textAlign: "center" }}>
  <img
    src="/img/fogwise/airbox-q900/qairt_sd21_output.webp"
    style={{ width: "65%" }}
  />
  output image
</div>

- 执行推理

    <NewCodeBlock tip="Device" type="device">

  ```bash
  python3 GenerativeAI/Image_Generation/stable_diffusion_v2_1/stable_diffusion_v2_1.py --chipset 9075 --prompt "a cat"
  ```

    </NewCodeBlock>

成功后会在示例目录下生成图片，例如：

```text
GenerativeAI/Image_Generation/stable_diffusion_v2_1/images/<timestamp>_512.jpg
```

AIRbox Q900 上首次运行会下载 Text Encoder / UNet / VAE 三份模型（合计约 1.2 GB 级），网络较慢时可能需数十分钟到数小时。

:::tip
依赖 `transformers` 与 `diffusers`。推荐直接运行脚本（避免 `run_inference.py --args` 对含空格 prompt 的引号问题）：

```bash
python3 GenerativeAI/Image_Generation/stable_diffusion_v2_1/stable_diffusion_v2_1.py --chipset 9075 --prompt "a cat"
```

:::
