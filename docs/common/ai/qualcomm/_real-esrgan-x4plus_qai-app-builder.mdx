此文档讲述使用 [QAI AppBuilder](../qai-appbuilder) Python API 利用 Qualcomm® Hexagon™ Processor (NPU) 推理 [Real-ESRGAN-x4plus](https://aihub.qualcomm.com/models/real_esrgan_x4plus?domain=Computer+Vision&useCase=Super+Resolution&chipsets=qualcomm-qcs6490-proxy)
图像超分模型。

**示例支持设备**

| 设备                 | SoC      |
| -------------------- | -------- |
| Dragon Q6A           | QCS6490  |
| Dragon Q8B           | SC8280XP |
| Fogwise® AIRbox Q900 | QCS9075  |

## 安装 QAI AppBuilder

:::tip

1. 请根据 [**QAI AppBuilder 安装方法**](../qai-appbuilder) 安装 QAI AppBuilder。

2. 请根据 [**创建 ADSP 环境变量**](../qai-appbuilder#创建-adsp-环境变量) 配置 ADSP 环境变量。
   :::

## 运行示例

### 安装依赖

在已激活的虚拟环境中安装示例依赖：

<NewCodeBlock tip="Device" type="device">

```bash
pip3 install requests tqdm qai-hub py3-wget Pillow torch torchvision opencv-python-headless
```

</NewCodeBlock>

### 运行脚本

- 进入上游示例目录

  <NewCodeBlock tip="Device" type="device">

  ```bash
  cd qai-appbuilder/samples
  ```

  </NewCodeBlock>

- 准备输入数据（示例自带输入文件时可直接运行；也可按脚本参数指定）

<div style={{ textAlign: "center" }}>
  <img
    src="/img/fogwise/airbox-q900/qairt_real_esrganx4plus_input.webp"
    style={{ width: "65%" }}
  />
  input image
</div>

执行推理

:::warning
在 QCS6490 / SC8280XP 上，**不要使用默认 float DLC**。默认 `.dlc` 会报 `The SocModel doesn't support FP16` 并导致加载失败。请使用 **`--bin`** 下载预编译 HTP context binary。
:::

<Tabs queryString="platform">
<TabItem value="QCS6490" default={props.tag === "qcs6490"} attributes={{className: props.tag !== "qcs6490" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Super_Resolution/real_esrgan_x4plus/real_esrgan_x4plus.py --chipset 6490 --bin --no_show
```

</NewCodeBlock>

</TabItem>
<TabItem value="SC8280XP" default={props.tag === "sc8280xp"} attributes={{className: props.tag !== "sc8280xp" && "tab_none"}}>

:::tip
SC8280XP 与 QCS6490 同为 Hexagon V68，下载模型时使用 `--chipset 6490`，并加 `--bin`。
:::

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Super_Resolution/real_esrgan_x4plus/real_esrgan_x4plus.py --chipset 6490 --bin --no_show
```

</NewCodeBlock>

</TabItem>
<TabItem value="QCS9075" default={props.tag === "qcs9075"} attributes={{className: props.tag !== "qcs9075" && "tab_none"}}>

<NewCodeBlock tip="Device" type="device">

```bash
python3 ComputerVision/Super_Resolution/real_esrgan_x4plus/real_esrgan_x4plus.py --chipset 9075 --no_show
```

</NewCodeBlock>

:::tip
QCS9075 上 Hub 默认下发 `.bin`（HTP context）即可运行。`--no_show` 用于无头环境。
:::

</TabItem>
</Tabs>

`--no_show` 用于无图形界面的 SSH/无头环境，避免弹出看图窗口。

### 预期结果

推理成功后会生成：

```text
ComputerVision/Super_Resolution/real_esrgan_x4plus/output.png
```

日志中可见类似 `Inference completed` 与输出路径信息。

:::tip
也可使用启动器：

```bash
python3 run_inference.py --model real_esrgan_x4plus --args "--chipset 6490 --bin --no_show"
```

:::
