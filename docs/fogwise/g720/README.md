# Radxa Fogwise G720

Radxa Fogwise G720 是面向工业接口连接、设备连接与现场部署的工业电脑，属于 [Fogwise 工业电脑系列](../README.md)。

## 整机与核心模组

Fogwise G720 基于 [Radxa OM-G720-L](../../osm/om-g720-l/README.md) OSM 核心模组。Fogwise G720 是工业整机名称，OM-G720-L 是用于整机集成的计算模组名称。
